# TI-Nspire CX II CAS 贪吃蛇

## 运行

将 `snake.tns` 用 TI-Nspire Student Software 或 TI-Nspire CX II Connect 传到计算器，在计算器的 My Documents 中打开它，然后在 Python 编辑器页按 Ctrl+R 运行。

`snake.py` 是游戏源码；计算器上请使用打包好的 `snake.tns` 文档。

## 操作

- 按任意方向键开始移动，之后用方向键控制蛇
- 回车：开始游戏 / 结束后重新开始
- ESC：结束游戏并退出

蛇吃到红色食物后得 1 分；穿过边界会从另一侧出现，撞到自己的身体时游戏结束。
