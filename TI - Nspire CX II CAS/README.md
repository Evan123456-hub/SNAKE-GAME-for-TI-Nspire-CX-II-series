# TI-Nspire CX II CAS Snake

## How to Run

1. Transfer `snake.tns` to your calculator using **TI-Nspire Student Software** or **TI-Nspire CX II Connect**.
2. Open the document from **My Documents** on your calculator.
3. In the Python Editor page, press **Ctrl + R** to run the game.

> Note: `snake.py` contains the source code. Please use the pre-packaged `snake.tns` file on your calculator.

## Controls

- **Arrow Keys**: Press any arrow key to start moving, then use them to control the snake's direction.
- **ENTER**: Start game / Restart game after Game Over.
- **ESC**: Exit the game.

## Gameplay

- Eat the red food to gain **1 point**.
- Passing through the screen boundaries will wrap the snake around to the opposite side.
- Colliding with your own body will result in **Game Over**.
